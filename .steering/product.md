# product.md — プロダクト要件定義

> **用途**：このプロジェクトが「何を・誰のために・なぜ作るか」を定義する。
> Claudeはタスク実施前にこのファイルを参照し、目的から外れた実装をしないこと。

---

## ゴール

Claude Code が現在使用しているモデル名とトークン使用量を、パルスメータ（心電図風の波形）でリアルタイム表示する Windows デスクトップツール「ClaudePulse」を提供する。

## ターゲットユーザー

- Windows 上で Claude Code を日常的に使う開発者（まずは担当者 ihira 本人）

## 解決したい課題

- Claude Code の利用中、いま「どのモデルで」「どれだけトークンを消費しているか」が一目で分からない
- ターミナルを切り替えずに、常駐の小窓で使用状況を"脈拍"として体感したい

## 成功の定義（完了条件）

- [ ] 起動すると即座に、直近で使用された Claude モデル名が表示される
- [ ] 入力／出力／キャッシュの各トークン数と合計が表示され、1秒間隔で自動更新される
- [ ] トークン消費の増分がパルスメータ（波形）としてリアルタイムに描画される
- [ ] Claude Code が動いていない（JSONLが見つからない）場合も、エラーにならず待機状態を表示する
- [ ] VS2022（x64 / Unicode / MFC共有DLL）でビルドが通り、Windows 10/11 で動作する

---

## スコープ

### In Scope（対象）
- `%USERPROFILE%\.claude\projects\` 配下の最新セッション JSONL の監視・解析
- モデル名、input / output / cache_read / cache_creation トークンの累計表示
- 増分トークンを心電図風波形で描画するパルスメータ表示
- プラン使用制限の表示（Claude Desktop の設定画面と同形式：セッション/週間の
  使用率プログレスバー＋「N% 使用済み」＋リセット時刻。ADR-006）
- ダイアログベースの単一ウィンドウ UI（ダークテーマ）

### Out of Scope（対象外）
- API 課金額（ドル換算）の計算・表示
- 複数セッションの同時監視、履歴のグラフ保存
- 使用量取得以外の Anthropic API アクセス（メッセージ送信等は行わない）
- OAuth トークンのリフレッシュ処理（期限切れ時は Claude Code の起動を促す）
- タスクトレイ常駐・通知機能（将来検討）
